MaadJokes 😂
MaadJokes is an Android app built with Kotlin and Jetpack Compose that displays random programming jokes through notifications.
Features
- 😂 Random programming jokes.
- 🔔 Scheduled notifications using WorkManager.
- 🔐 Notification permission handling (Android 13+).
- ⚙️ Redirect to notification settings if permission is denied.
- 🌐 Open Android Compose documentation by clicking the notification.
Technologies
- Kotlin
- Jetpack Compose
- WorkManager
- NotificationManager
- Material 3
Purpose
A simple project for learning Android notifications, runtime permissions, and background task scheduling.
